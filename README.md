# gigi chat

Месенджер у реальному часі: вхід за нікнеймом, пошук друзів, історія повідомлень, тема в стилі Telegram, інтерфейс англійською, українською та російською.

## Структура

```
gigi-chat/
├── server.js         # Express + Socket.io + SQLite
├── package.json
├── public/
│   └── index.html    # весь фронтенд (HTML/CSS/JS в одному файлі)
└── README.md
```

## Локальний запуск

1. Встановіть Node.js 18 або новіше (https://nodejs.org).
2. Відкрийте папку `gigi-chat` у терміналі.
3. Встановіть залежності:
   ```bash
   npm install
   ```
4. Запустіть сервер:
   ```bash
   npm start
   ```
5. Відкрийте http://localhost:3000 у двох вкладках або двох браузерах, введіть різні нікнейми й пишіть одне одному.

Повідомлення зберігаються у файлі `gigi.db` (SQLite) поруч із `server.js`.

## Деплой, щоб друзі могли приєднатися

Socket.io потребує постійного з'єднання, тому Vercel не підходить. Використовуйте Render або Railway.

### Render (безкоштовний план з обмеженнями)

1. Завантажте папку на GitHub.
2. На https://render.com створіть **New → Web Service** і виберіть репозиторій.
3. Налаштування:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
4. Додайте змінну середовища `DB_FILE=/var/data/gigi.db` і підключіть **Disk** з монтуванням у `/var/data`, щоб історія не губилася після перезапуску.
5. Отримаєте посилання виду `https://gigi-chat.onrender.com`. Надішліть його друзям.

### Railway

1. Створіть проєкт з GitHub-репозиторію.
2. Railway сам визначить `npm start`.
3. Додайте Volume, змонтований у `/data`, і змінну `DB_FILE=/data/gigi.db`.
4. Включіть публічний домен у Settings → Networking.

## Важливо знати

- Вхід без пароля: будь-хто може обрати вже зайнятий нікнейм. Для публічного використання варто додати пароль або код входу.
- Повідомлення не шифруються наскрізно. Сервер бачить їх у незашифрованому вигляді.
- Непрочитані лічильники не зберігаються після перезавантаження сторінки.
- Для великої кількості користувачів SQLite і одного сервера достатньо лише для невеликої групи друзів.
